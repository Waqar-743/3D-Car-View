# Windway Jungle SVG Pack

25 original, editable SVG illustrations for the Jungle Circuit. Each individual asset uses a transparent background, `viewBox="0 0 256 256"`, accessible `title` / `desc`, rounded deep-pine outlines and a distinct jungle palette.

Open `index.html` through the app's preview server for the searchable gallery, large previews and individual downloads. No external libraries, fonts, images or network resources are required.

## Categories

- Wildlife (9): lion, giraffe, deer, python, horse, wolf, monkey, toucan, elephant.
- Characters (3): WAQAR, IMRAN, TATHEER.
- Environment (5): broadleaf tree, palm tree, fern, vines, river.
- Race kit (8): stop station, lap badge, finish flag, track minimap, winner trophy, checkpoint, boost ramp, jungle badge.

WAQAR, IMRAN and TATHEER are friendly original fictional character designs, not likenesses of real people. Their visible labels are SVG text; the fallback font stack is Trebuchet MS / Arial / sans-serif.

## Files

- `manifest.json`: asset names, categories, descriptions and file paths.
- `index.html`: responsive, keyboard-accessible gallery with search, filters and modal previews.
- `contact-sheet.svg`: all 25 drawings embedded as editable vector markup in one labelled sheet.
- `contact-sheet.png`: rendered preview of that sheet.
- Individual `*.svg` files: the actual game-ready vector assets.

The Jungle pack is separate from the Alpine `cartoon-pack`; no original assets were replaced.
