# Windway — Frostbite Ascent SVG pack

Eighteen original winter SVG drawings for the expert summit climb. Each individual asset is self-contained, has a transparent exterior, a 256 × 256 viewBox and accessible title/description metadata.

Open `index.html` for large previews and downloads. The game link selects `?map=snow`. `contact-sheet.svg` embeds every drawing as editable vector paths; `contact-sheet.png` is the rendered overview.

Palette: deep steel #263d52, powder #f3f8fb, ice #b9e1ed, frost blue #7aa7bf and rescue coral #d47762. UI buttons use the lighter coral #e7a692 for readable dark text.

Assets: snowman, snowy-tree, snowy-mountain, ice-patch, ice-warning, snowbank, snow-boulder, slalom-gate, summit-flag, summit-trophy, mountain-hut, track-minimap, route-badge, checkpoint, wind-gust, snowflake, arctic-fox, penguin.

The animals and snowman are fictional cartoon spectators, not physical hazards. The game’s solid snow-block obstacles and marked ice zones are defined separately in `src/game/snowCourse.ts` so their visible meshes and collision/handling data agree.
